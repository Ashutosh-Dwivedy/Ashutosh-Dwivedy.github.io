PortPatrol

Automated port scanner & Linux security hardening utility — Python

Most open ports on a personal or self-hosted Linux system go unnoticed until they're exploited. Tools like Nmap are excellent at finding them, but stop at detection — the user is left to research the service, decide if it's risky, and figure out how to fix it across several distro-specific commands. PortPatrol closes that gap: it scans, identifies, and remediates in one guided workflow.

It runs a multithreaded scan across a configurable port range using a thread-safe work queue, double-checks every result to rule out transient false positives, then queries the kernel's live socket table directly via ss -tunlp to identify the exact process and PID behind each open port — filtering out anything essential (PID < 1000) so you can't accidentally disable a core service. For whatever's left, it presents five remediation options — block, kill, upgrade, deploy fail2ban, or skip — and executes the right command for your distro automatically, whether that's ufw, firewall-cmd, or iptables.

Design decision

Early versions used banner grabbing to identify services — reading what each service announces about itself. It worked, but banners can be spoofed, silent, or simply absent. Since PortPatrol is built for hardening the local machine (not scanning remote, unknown targets), I switched to querying the kernel's socket table directly via ss instead — it reports exactly what the OS knows to be true, not what a service chooses to say about itself.
